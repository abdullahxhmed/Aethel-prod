## Slide 4: How It Works

# **The Verification Workflow**

### 1. **Report**
- User takes photo and reports issue
- GPS location automatically captured
- Issue appears on public map

### 2. **Acknowledge**
- City marks issue as "In Progress"
- Community can track status changes

### 3. **Resolve**
- City marks as "Resolved (Pending Verification)"
- Community verification phase begins

### 4. **Verify**
- **Community votes**: "Fixed?" Yes/No
- **Threshold reached**: 3 "Yes" votes = "Verified"
- **Dispute process**: "No" vote requires photo evidence
